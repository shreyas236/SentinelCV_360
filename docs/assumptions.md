# Assumptions

The prototype assumes a trusted operating system, authorized workstation operator, protected keystore secret and signed approved reference. Hosted demo ownership is private. Local sessions bind a fixed role; password setup and source dependencies are prepared before network disconnection.

The included images are synthetic RGB test cards, not photos, recorded CCTV or drone footage. Their classes are color-domain labels. The feature classifier is intentionally small, interpretable and deterministic. Declared dataset training lineage does not prove how weights were trained. Provenance establishes integrity within this trust model, not correctness of the CV prediction.
